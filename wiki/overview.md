# Overview

这是“小星星历史地图馆”的知识生产后台。

它不直接服务最终儿童网站，而是负责：

- 结构化整理史料
- 维护人物、事件、地点、势力、关系、地图图层
- 区分正史、演义、传说和儿童改写
- 为后续前端导出稳定的 JSON / YAML / GeoJSON

## Current Objective

第一阶段聚焦《三国形成篇》MVP，时间范围为 `184—229`。

要先做稳的不是页面炫技，而是底层知识结构：

- 时间节点
- 地点与地图图层
- 人物与势力
- 事件因果
- 儿童版与家长版叙事分层

## Canonical Workflow

1. 把原始资料放进 `raw/sources/`
2. 在 `wiki/sources/` 中形成来源页或读书页
3. 抽取 canonical entities
4. 形成人工审核后的事件、人物、地点、势力、关系页
5. 再导出到产品数据层

## Source Strategy

来源体系现在采用两步法：

- 来源框架一次性搭好
- 来源内容按故事节点逐条补充

当前《三国形成篇》的优先来源是：

- 后汉书
- 三国志
- 资治通鉴
- 三国演义
- 家长讲述 / 亲子讲义
- 小朋友复述 / 反馈

`史记` 已经被纳入长期来源体系，但优先留给春秋战国和楚汉模块重用。

## This Wiki Is Not

- 不是最终产品数据库
- 不是未经审核的 AI 历史生成器
- 不是直接给孩子浏览的前台网站

## Current Content Coverage

截至2026年5月11日，本维基已涵盖以下主题：

### 核心事件
- **黄巾起义（184年）**：东汉末年规模最大的农民起义，由张角领导。虽然被镇压，但动摇了东汉统治，开启了三国时代序幕。已建立事件页、儿童版故事、家长说明、亲子共读记录和儿童认知反馈记录。

### 核心人物
- **张角**：黄巾起义领袖，太平道创始人
- **曹操**：东汉末年军阀，三国时期魏国奠基人（时间参照点）

### 核心势力
- **东汉**：形式上存在但实质瓦解的中央政权
- **黄巾军**：由贫苦农民组成的起义军

### 核心概念
- **历史因果关系**：事件之间的因果联系，特别是失败事件如何产生深远影响
- **历史重要性**：事件的历史意义不取决于直接成败

### 待发展领域

- 地点与地图图层
- 关系建模
- 儿童叙事模板与家长讲解框架
