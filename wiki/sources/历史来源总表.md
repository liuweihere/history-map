# 历史来源总表

这张表不是把史书一次性导完，而是先把长期会用到的来源体系登记清楚，方便后续按故事节点逐条补内容。

## 使用原则

- 先建立来源框架，再逐条补内容
- 先做《三国形成篇》高频来源，再扩到春秋、楚汉等模块
- 正史、文学、教学材料必须分层，不混用
- source page 可以晚于 raw source 细化，但不能跳过来源登记

## 录入策略

### 一次性建立

- 来源总表
- 来源类型定义
- raw 目录分层
- source page 模板

### 逐条补充

- 某个故事节点真正需要的史料提要
- 该节点的亲子讲述记录
- 该节点的小朋友复述反馈
- 与该节点直接相关的地图说明
