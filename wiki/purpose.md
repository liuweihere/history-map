# Project Purpose

## Goal

构建一个面向儿童的中国历史知识系统，核心表达方式是：

- 时间轴
- 地图变化
- 人物关系
- 关键事件
- 儿童友好叙事
- 家长辅助讲解

本项目不是传统百科，也不是单纯故事集，而是一个“时间化历史知识图谱 + 地图叙事系统”的知识生产后台。

## Key Questions

1. 如何让孩子看见历史在时间中的变化？
2. 如何把事件、人物、地点、势力放进统一的知识结构？
3. 如何区分正史、演义、传说和儿童改写？
4. 如何把历史知识导出为可供网站地图和时间轴渲染的数据？
5. 如何先完成《三国形成篇》的 MVP？

## Scope

**In scope:**
- 中国历史启蒙内容的结构化整理
- 人物、事件、地点、势力、关系、地图图层建模
- 儿童版叙事与家长版说明
- 正史 / 演义 / 传说的标注区分
- 《三国形成篇》MVP 设计与内容生产
- 为前端导出 JSON / YAML / GeoJSON 的数据契约设计

**Out of scope:**
- 直接作为线上产品数据库
- 直接承载儿童端学习进度和账号系统
- 未审核内容直接发布
- 用 AI 直接决定史实真伪

## Thesis

历史启蒙最适合通过“时间 + 空间 + 人物 + 因果”来建立系统理解。

《三国形成篇》是最适合作为第一期 MVP 的主题，因为它同时具备：
- 清晰时间节点
- 清晰势力变化
- 清晰关键人物
- 清晰地图变化
- 清晰因果链条
